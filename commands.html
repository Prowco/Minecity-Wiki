Reference/Command Dictionary

Command Dictionary

Complete command reference. In-game /help remains the final authority — if a command is not listed there, you do not have permission for it.

Tip: every command cell is clickable — click to copy.

Notes

Note

Minecity uses its own permission scheme for police and medical roles. Granting essentials. does not give police powers, and granting police. does not give admin access.

Tip

Unsure which plugin owns a command? Type /help <command> — Bukkit prints the owning plugin and the usage string.
