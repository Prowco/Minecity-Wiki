Reference/Permission Matrix

Permission Matrix

Permissions are managed by LuckPerms. Data lives in a database, so you edit it in-game with /lp commands or the web editor — never by editing YAML files.

Useful LuckPerms commands

CommandPurpose
/lp user <p> permission set <node> trueGrant a node
/lp user <p> permission unset <node>Remove a node
/lp user <p> parent add <group>Add to a group
/lp user <p> infoShow effective permissions
/lp group <g> permission set <node> trueGrant to a group
/lp verbose onLive permission debugging

Debugging "I can't use this command"

  1. Is the node spelled exactly right? police.officer, not police.officers.
  2. Is a negative permission overriding it higher up the tree?
  3. Is the player in the right group, with a correct parent chain?
  4. Did the plugin register the node? /lp verbose on shows live checks.
  5. Did you reload? Some plugins cache permissions until rejoin.
Tip

/lp user <player> info and read the effective permissions section first. Inheritance surprises cause most permission bugs.
