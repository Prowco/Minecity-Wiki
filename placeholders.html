Placeholder Guide

Placeholders are dynamic values other plugins can read — %player_name%, %vault_eco_balance_formatted%, %police_stars%. They are the glue between the custom core and the interface plugins.

The format

%expansion_identifier%

If an expansion does not resolve, the token appears literally on screen. That is the first thing to check when a scoreboard shows %police_stars% instead of 3.

Survival — %minecity_*%

PlaceholderExampleMeaning
%minecity_hydration%78Hydration, numeric
%minecity_hydration_percent%78%Hydration with sign
%minecity_hydration_bar%■■■■■■■□□□Coloured bar
%minecity_hunger%92Hunger, numeric
%minecity_hunger_percent%92%Hunger with sign
%minecity_hunger_bar%■■■■■■■■■□Coloured bar
%minecity_survival_status%💧78% 🍖92%Combined widget
%minecity_is_critical%true / falseBoth stats at zero

Police — %police_*%

PlaceholderExampleMeaning
%police_stars%3Numeric wanted level
%police_stars_tag%★★★☆☆Star glyphs
%police_is_wanted%Yes / NoHas any stars
%police_wanted_status%WANTED (3★)Decorated status
%police_is_jailed%true / falseCurrently imprisoned
%police_jail_time%240Seconds remaining
%police_is_handcuffed%true / falseCurrently cuffed

Medical — %paramedic_% / %ems_%

PlaceholderExampleMeaning
%paramedic_is_on_duty%Yes / NoParamedic on shift
%paramedic_prefix%[EMS]Duty prefix
%paramedic_is_sick%Yes / NoHas a condition
%paramedic_disease%Broken LegActive condition
%paramedic_is_downed%true / falseBleeding out
%paramedic_downed_seconds%45Seconds until death
%paramedic_active_calls%4Downed players city-wide

%vault_eco_balance_formatted%12,450.00Bank balance
%autorank_current_path%ResidenteCurrent citizen level

Debugging

SymptomCauseFix
Token appears literallyExpansion not loaded/papi list, then /papi reload
Empty valuePlaceholder needs a player contextUse a player-scoped token
Wrong valueWrong expansion/papi parse me %token% to test
Breaks after restartExpansion jar missingCheck plugins/PlaceholderAPI/expansions/
/papi list                     registered expansions
/papi parse me %police_stars%  test a token against yourself
/papi reload                   reload expansions
Tip

Always test with /papi parse me %token% before wiring a placeholder into TAB or a hologram. Two seconds now saves twenty minutes of guessing later.
